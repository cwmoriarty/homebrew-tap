# Cwmoriarty Tap

## How do I install these formulae?

`brew install cwmoriarty/tap/<formula>`

Or `brew tap cwmoriarty/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cwmoriarty/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
